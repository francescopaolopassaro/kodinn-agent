# Security

Please report security problems privately to **kodinn@digitalsolutions.it** rather than in a public issue. Include
the version (`kodinn --version`), your system, and the steps to reproduce. You will get an answer within a few days.

Packages are published at `https://www.digitalsolutions.it/downloads/kodinncli/<version>/` with their SHA-256 in
`latest.json` and `SHA256SUMS.txt`; every installer and the in-app updater checks it before installing.
